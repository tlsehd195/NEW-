# ADR-0219: Lock 2016-07-11..2020-08-28 as TEST-3

**Status:** Accepted
**Date:** 2026-09-27
**Deciders:** account owner, Claude Code session

**Related documents:** `ADR-0041` (TEST-1), `ADR-0209` (TEST-2),
`ADR-0212` (Stage 5 / 2000-onward window), `ADR-0213` (price catalog),
`src/strategy_research/locked_windows.py`,
`docs/research/reports/full-validation-20260927T065335Z.json`.

## Context

`run_full_validation.yml` ran price-only on `RESEARCH_UNIVERSE_STAGE5`
(203 symbols) over 2000-01-01..2020-08-28. Its default 60/20/20 split
put the held-out TEST at 2016-07-11..2020-08-28, so all 22 price
candidates were evaluated against that range. Earlier stage4 runs
(2010-01-01..2020-08-28) had already used 2018-07-11..2020-08-28 as TEST
without it being locked.

Results on that window: all 22 INCONCLUSIVE (PBO 0.30). Only
`illiquidity` reached CANDIDATE on the walk-forward folds (DSR 0.98),
and it trailed SPY by 47.9pp on TEST (-41.8% max drawdown). Six
momentum-like candidates beat SPY on TEST (`downside_beta` +22.6pp,
`long_term_momentum` +16.1pp, `rs_rating` +13.6pp, `coskewness`
+13.4pp, `risk_controlled_momentum` +11.3pp, `price_delay` +5.9pp), but
none cleared Deflated Sharpe >= 0.95.

## Decision

Register `TEST_3` (2016-07-11..2020-08-28, the 22 candidates as
`observed_by`), the same retroactive lock `ADR-0209` applied to TEST-2.
`earliest_locked_window_start()` becomes 2016-07-11, so every script
defaulting to it now stops there, and `run_full_validation.yml`'s `end`
default moves to 2016-07-11. Synthetic end-to-end tests whose date
ranges fell inside the new window were shifted six years earlier; what
they check is unchanged.

## Consequences

- New factor research has 2000-01-01..2016-07-11 (the price catalog) or
  2010-01-01..2016-07-11 (the stage4 fundamentals catalogs). A 60/20/20
  split of 2000..2016-07-11 leaves a TEST of about 3.3 years.
- Any in-flight study ending at 2020-08-28 is refused by the locked-window
  guards and has to end at 2016-07-11.
- The survivorship-bias limitation of `ADR-0212` applies to the numbers
  above.
- Found while reading this report, not changed here: `buy_and_hold`
  returned +8.8% (5.5% volatility) on TEST because $10,000 split over 203
  symbols is about $48 per symbol and `BuyAndHoldStrategy` buys whole
  shares only (`src/backtest/strategy.py:94`), so most of the baseline
  stays in cash. Factor strategies (5 names, about $2,000 each) are only
  affected for the few symbols priced above that. SPY, the benchmark
  the verdicts use, is unaffected.
