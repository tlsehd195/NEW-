# ADR-0222: Lock 2016-07-11..2020-08-28 as TEST-3; screening runs skip the held-out TEST

**Status:** Accepted
**Date:** 2026-09-27
**Deciders:** account owner, Claude Code session

**Related documents:** `ADR-0041` (TEST-1), `ADR-0209` (TEST-2),
`ADR-0212` (Stage 5 / 2000-onward window), `ADR-0213` (price catalog),
`src/strategy_research/locked_windows.py`,
`docs/research/reports/full-validation-20260927T065335Z.json`.

## Context

`run_full_validation.yml` ran price-only on `RESEARCH_UNIVERSE_STAGE5`
(203 symbols) over 2000-01-01..2020-08-28. Its default 60/20/20 split
put the held-out TEST at 2016-07-11..2020-08-28, so all 22 price
candidates were evaluated against that range. Earlier stage4 runs
(2010-01-01..2020-08-28) had already used 2018-07-11..2020-08-28 as TEST
without it being locked.

The first run (`full-validation-20260927T065335Z.json`) used the
rebalance sizing that `ADR-0219` then fixed, so it was re-run once on the
same split with the fixed code (main at `18c7741`). The workflow computed
it three times but lost the report commit to a push race each time, so
the stored report (`full-validation-20260927T091846Z.json`, experiment
`cb16966617b12245`) comes from the same command run locally against the
same release. Re-running on the already-observed window only corrects a
harness bug; no candidate or parameter was changed or chosen from it.

Post-fix results on that window: all 22 INCONCLUSIVE (PBO 0.23). Only
`illiquidity` reached CANDIDATE on the walk-forward folds (DSR 0.98),
and it trailed SPY (+76.5%) by 41.2pp on TEST (-40.0% max drawdown). Nine
candidates beat SPY on TEST (largest: `residual_momentum` +75.8pp,
`rs_rating` +71.5pp, `long_term_momentum` +58.7pp), none of them with
Deflated Sharpe >= 0.95, and their max drawdowns ran -22% to -53%.

## Why a second rule

Every validation run so far carved a fresh held-out TEST out of its own
range and backtested all candidates on it. TEST-2 and TEST-3 were both
locked after the fact for that reason, and each lock shrinks the
unobserved history. At that rate the 2000..2016 research range would
be spent after two or three more runs. The account owner raised this
(2026-09-27) and asked the session to pick the approach.

## Decision

Register `TEST_3` (2016-07-11..2020-08-28, the 22 candidates as
`observed_by`), the same retroactive lock `ADR-0209` applied to TEST-2.
`earliest_locked_window_start()` becomes 2016-07-11, so every script
defaulting to it now stops there, and `run_full_validation.yml`'s `end`
default moves to 2016-07-11. Screening runs no longer touch the held-out TEST:
`run_long_horizon_validation.py --skip-held-out` runs only the
walk-forward folds over TRAIN+VALIDATION, and `run_full_validation.yml`
passes it unless the new `final_exam` input is set. The procedure from
here is: screen candidates on the folds as often as needed, narrow to a
short list of finalists, run `final_exam=true` once for that list, then
lock the TEST window it used. Paper trading on data after 2026-08-27
remains the forward test no backtest can replace.
`run_full_validation.yml` also rebases the report commit onto the
moved branch before pushing. Synthetic end-to-end tests whose date
ranges fell inside the new window were shifted six years earlier; what
they check is unchanged.

## Consequences

- New factor research has 2000-01-01..2016-07-11 (the price catalog) or
  2010-01-01..2016-07-11 (the stage4 fundamentals catalogs). A 60/20/20
  split of 2000..2016-07-11 leaves a TEST of about 3.3 years.
- Any in-flight study ending at 2020-08-28 is refused by the locked-window
  guards and has to end at 2016-07-11.
  `run_macro_filter_validation.yml`'s `end` default moves from
  2020-08-27 to 2016-07-10 for that reason (`ADR-0220`).
- The survivorship-bias limitation of `ADR-0212` applies to the numbers
  above.
- Found while reading this report, not changed here: `buy_and_hold`
  returned +8.8% (5.5% volatility) on TEST because $10,000 split over 203
  symbols is about $48 per symbol and `BuyAndHoldStrategy` buys whole
  shares only (`src/backtest/strategy.py:94`), so most of the baseline
  stays in cash. Factor strategies (5 names, about $2,000 each) are only
  affected for the few symbols priced above that. SPY, the benchmark
  the verdicts use, is unaffected.
